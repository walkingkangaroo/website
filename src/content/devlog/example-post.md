This is an example. It is a draft, so it shows up while the site is running locally and never in the published site. It is here to show how each part of a post looks. Grant's real posts replace it.

## A second-level heading

A paragraph of running text, with **bold words**, some _emphasis_ and a [link to the Common Ground page](/projects/common-ground/). Paragraphs stay at a comfortable width so the lines are easy to read.

### A third-level heading

A list of things:

- A first item
- A second item, a little longer than the first so it can wrap onto a second line on a phone
- A third item

And a numbered list:

1. Do the first thing
2. Do the second thing
3. Do the third thing

> A quotation, set apart from the text around it.

Inline `code` sits in a sentence. A block of code looks like this:

```
position = start + direction * speed * delta
if (position.y < ground) { position.y = ground }
```

That is every part of a post.
