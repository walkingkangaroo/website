# 0001. The site follows direction B2 · Daylight, built from the brand pack

- **Status:** Accepted; the hero layout is superseded by [0022](0022-hero-text-beside-the-cover.md)
- **Date:** 2026-10-05
- **Issues:** —

## Context

Three home-page directions were wireframed: A · Paper trail, B · Night walk (Ink ground) and
C · Field journal. Grant liked B but wanted a lighter theme, so B was redrawn on Paper as B2.

## Decision

Build to the B2 · Daylight board on https://claude.ai/artifact/RoieMJiNMKNuXoEvUmwK5y: a featured
project hero with a footprint trail, project cards, a footprint stage meter (Idea, Prototype,
Alpha, Beta, Launch), a devlog, an about section in Grant's own voice, and a newsletter band.
Colours, type, logos and icons come from the Walking Kangaroo brand pack, unchanged.

## Alternatives considered

- **A · Paper trail:** fine, but Grant preferred B's big featured hero.
- **B · Night walk:** the layout won; the dark theme didn't.
- **C · Field journal:** more personal list layout; not chosen.

## Consequences

- The stage meter always shows the stage name in text too, so it doesn't rely on the prints.
- Rust on Ink and Rust Light on Paper fail contrast and are never used for text.
