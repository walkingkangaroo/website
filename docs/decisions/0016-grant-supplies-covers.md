# 0016. Grant supplies each project's cover art

- **Status:** Accepted
- **Date:** 2026-10-06
- **Issues:** KAN-753
- **Round:** [docs/rounds/content.md](../rounds/content.md), question 3

## Context

None of the five repos has key art. Arcsine's and Perso's images are concept mockups, not the
games.

## Decision

Grant supplies a cover for each project and attaches it to that project's Linear issue. The
issue copies it in unchanged apart from resizing, and never makes or edits art. Concept mockups
are never shown as gameplay.

## Alternatives considered

- **A frame from the clip:** no clips this step (0015).

## Consequences

- Each project issue is blocked until its cover arrives.
- One cover serves the 3:4 card, the wide hero, the 16:9 page panel and the share image, so the
  subject belongs in the middle of the frame.
