# 0018. Project pages leave out "Working on now"

- **Status:** Accepted
- **Date:** 2026-10-06
- **Issues:** KAN-753
- **Round:** [docs/rounds/content.md](../rounds/content.md), question 5

## Context

The project page shows a "Working on now" panel when the file has items. Nothing keeps it current.

## Decision

No project file has `workingOn` for now. The panel stays built and hidden.

## Alternatives considered

- **Three lines per project:** a stale list reads worse than none.

## Consequences

- Grant can add it to any project by editing its file.
